# 首页分镜与视觉规范

设计概念：**一场由奇怪的想象力发起的火星旅行**。页面本身是一段随滚动推进的旅程，真实实验作品成为开场照片墙；鹈鹕、鳄鱼与星舰是贯穿场景的叙事主角。以下是分镜设计，尚未制作视觉稿或动效。

## 视觉语言

- 纸张白 `#F6F8FC`：作品底板，保持细节可读。
- 晴空蓝 `#99D8EE`：地面旅程与开场环境。
- 深海蓝 `#163B63`：正文、导航与场景阴影。
- 鳄鱼绿 `#4C8065`：角色识别色，来自鳄鱼形象。
- 星舰银 `#C6D0DE`：舰体与引擎剖面构造。
- 火星红 `#C66348`：终幕地貌，随剧情才大面积出现。

拉丁标题建议 Space Grotesk，中文与界面使用 Noto Sans SC 或系统中文字体；标题紧凑而大，正文克制，首次制作时验证所选字体授权并按需子集化。标题不靠霓虹渐变或大量数据卡片建立识别感，而是让主角轨迹贯穿画面。

页面布局以一个连续舞台为核心。叙事字幕靠屏幕侧边、左对齐；照片墙可以突破内容边界；投票区域保持稳定、平静。导航提供“实验 / 盲测 / 排行榜”，整个旅程有“跳过故事”。

## 五幕分镜

滚动百分比是设计初值，实施按内容、设备和可用高度调整。

| 幕         | 时间 / 进度              | 画面与镜头                                                                                         |
| ---------- | ------------------------ | -------------------------------------------------------------------------------------------------- |
| 照片星云   | 入场约 1.8–2.5 秒；0–15% | 模型作品的小照片从四边和远近层飞入，最终拼成一面略带透视的大照片墙；中间留出标题与入口，不遮盖作品 |
| 公路相遇   | 15–40%                   | 滚动使照片墙后退，地面线出现；鹈鹕骑车从左入场，鳄鱼骑摩托从右侧赶来；车轮与位移同步               |
| 遇见星舰   | 40–65%                   | 道路延伸至发射场；镜头上移看见星舰；舰体局部展开为引擎剖面，实验作品在可读的独立画框中出现         |
| 登船与点火 | 65–85%                   | 两位主角停好车辆，沿舷梯/升降台进入舱内；通过舷窗继续看见它们；引擎亮起，星舰沿竖直方向升空        |
| 飞向火星   | 85–100%                  | 天空渐深、地球缩小，火星从远处扩大进入视野；两位主角通过舷窗看向火星，最后出现实验与盲测入口       |

各幕交互：照片墙定格后可打开作品；公路幕可进入鹈鹕/鳄鱼实验；剖面幕可放大阅读并进入星舰实验；登船幕保持跳过入口；终幕提供“开始盲测”和“探索全部实验”。旅程终点默认飞向火星的观景画面，如要着陆可在后续加短尾声。

```text
┌ 实验    盲测    排行榜                         开始盲测 ┐
│       ↘  真实作品照片从周边聚拢  ↙                        │
│  [作品][作品]     奇怪的想象力，准备起飞。     [作品]      │
│       [作品][作品][作品][作品][作品][作品]                │
│             进入盲测       继续向下探索                  │
└────────────────────────────────────────────────────────┘
         骑车的鹈鹕  ───── 公路 ─────  骑摩托的鳄鱼
                              ↓
                    发射场 / 星舰引擎剖面
                              ↓
                    登船 / 点火 / 飞向火星
```

照片“汇聚成墙”首期指作品组成的大型拼贴。如果希望远看整个墙还组成一只巨大鹈鹕，需要另做基于缩略图颜色匹配的马赛克布局；29 幅作品不足以形成精细轮廓，可重复使用装饰缩略图，但不得让用户误认成更多独立作品。

## 动效实现

首期建议 **2.5D**：CSS perspective + 多层 SVG/透明图 + GSAP ScrollTrigger。照片墙用固定种子的起始位置，减少服务端/客户端布局差异；入场按时间运行一次，之后以单一滚动进度驱动主时间轴。用户快速滚动可直接推进，不锁滚轮、不强迫等待片头结束。

照片飞入、道路位移、舰体升空优先变换 `transform / opacity`。车轮旋转、腿部摆动和舱门开合使用可控分组的角色 SVG；镜头视差通过前景、中景、背景速度差实现。引擎“展开”要准备拆分零件素材，单张完整作品不能自动变成可用的机械解剖动画。

GSAP 统一管理场景时序，清理卸载实例并重算尺寸；不同时让 React render 和多个动画库争抢相同 transform。滚动事件不逐帧更新 React 全局状态。低频界面状态只记录当前章节和交互。

Three.js / React Three Fiber 仅在确实需要自由旋转舰体、动态光照或真正穿过引擎内部时引入。完整 3D 还需要建模、材质、压缩与移动端适配；当前叙事使用分层素材即可成立。

## 必须准备的素材

| 素材     | 要求                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 实验作品 | 29 个已有鹈鹕 SVG 的合规展示预览；鳄鱼与星舰实验作品后续补充                             |
| 鹈鹕角色 | 统一造型；身体、嘴、翅膀、腿、自行车轮可分别动画；登船/舷窗姿态                          |
| 鳄鱼角色 | 统一造型；身体、尾巴、四肢、摩托轮分层；停车/登船/舷窗姿态                               |
| 星舰     | 外观、剖面组件、舱门、舷窗、引擎火焰层；明确这是艺术叙事和 AI 实验，不作为工程准确性资料 |
| 环境     | 道路、发射台、云层、星空、地球和火星；按近中远景分层                                     |

叙事角色采用专门设计的统一形象，不从每个模型的作品中随机换造型。真实作品用于照片墙和实验展示。星舰技术图在 Arena 中的评判可包括构图、标注可读性、遵循提示词；未经专家核验不能把“视觉偏好”称为“工程准确度”。

## 性能与可访问性验收目标

- 首屏先显示可读静态内容与入口，再启动动画；前 8–12 张可见缩略图优先加载，其余分批进入。
- 桌面照片粒子初值 24–40，手机 10–16；布局密度随屏幕调整，不同时解码全部高分辨率原件。
- 以移动端真实设备测试为准；目标 LCP ≤2.5s、INP ≤200ms、CLS ≤0.1，动画尽量接近 60fps。这些是验收目标，尚未实测。
- 后续场景接近视口再加载；离屏停止装饰动画。缩略图和场景素材采用明确尺寸，避免布局位移。
- `prefers-reduced-motion` 下展示静态章节和可点击作品墙；低性能设备可以选择简化模式。
- 固定舞台保留语义化章节、文字和链接；键盘无需穿越 Canvas 才能进入实验；信息不只靠颜色表达。
- 手机缩短镜头停留和场景长度，保留相同故事顺序。默认无声音，音效必须用户主动开启。
- 重复访问默认直接进入定格照片墙，可以主动重播；无 JavaScript 时仍能通过页面链接浏览实验。

设计自检：把视觉大胆之处集中在“连续旅行”，Arena 不复制首页的飞入和镜头运动；真实作品保持大面积可读，不把评测体验淹没在装饰中。
