导入映射建议：

- `id / svgKey` → 保留为旧来源标识，命名空间去重，不直接作为盲测公开标识。
- `category` → 实验 slug 映射，例如 `pelican-on-a-bicycle`。
- `modelName / title` → 分别保留原始标识与展示标签，审核名称差异，不根据拼写猜测真实型号。
- `svgUrl` → 原始来源；实际导入后生成中性资源键。HTTP 来源要验证对应 HTTPS 是否可用，不能只替换字符串就宣称迁移成功。
- `generationTimeMs / tokenUsage` → 可空指标，页面显示“未记录”，不能填 0 或据此错误比较效率。
- 旧评分和胜负计数 → `legacyStats`，不导入成新站的可审计评分。
- `status=1` → 旧状态原样记录；发布前确认含义和素材审核，不把未知状态值自动当成已审安全标记。

当前缺少：明确的完整提示词、采样参数/推理配置、每模型重复生成样本、SVG 的实际有效性与尺寸、素材许可、原始逐票历史。鳄鱼骑摩托与星舰引擎剖面尚未出现在这份附件中。

前四个有对战记录的作品只能证明旧数据中存在统计；没有用户身份与 Vote 明细，无法还原“谁评价了哪些图片”。首版不实现个人记录；新站从上线后的无账户投票开始积累可重算的排名数据。
